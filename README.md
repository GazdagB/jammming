# 🎧 React + Vite Spotify Playlist App

This project is an experimental Spotify playlist creation app built using the Spotify Web API. It was developed as part of the Codecademy Fullstack Path curriculum. 🎓

## 🚀 Live Demo
🌐 Check out the live version here: [Live Demo](https://gb-jamming.netlify.app/)

## ✨ Features
* 🔐 Log in to your Spotify account
* 🔎 Search for tracks
* 📃 Create custom playlists
* ➕➖ Add and remove tracks from your playlist

## 🛠️ Technologies Used
* ⚡ Vite
* ⚛️ React
* 📡 Axios

## 📚 How to Use
* 🔑 Click Login to authenticate with Spotify.
* 🔍 Use the search bar to find your favorite tracks.
* ➕ Click Add to include them in your playlist.
* 📝 Give your playlist a name.
* 💾 Click Save to Spotify and it’ll appear in your Spotify account!

## 🧠 Lessons Learned
* Working with OAuth 2.0 authentication flow
* Managing API calls and authorization headers
* Handling state and component-based UI updates in React
* Building a frontend connected to a 3rd-party API
